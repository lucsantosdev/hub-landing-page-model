# 💄 Beauty Salon — Landing Page Model

A fully responsive, multi-language landing page model for a beauty salon & spa business. Built with clean HTML5, CSS3, and Bootstrap 4, this template is ideal as a starting point for beauty, wellness, or personal care brand websites.

> **Live Brand:** Labspa — *New York's boutique beauty & wellness destination*

## 📄 Page Sections

### 1. Header (Fixed)
- Brand logo centered between nav and contact info
- Navigation links: Home, About, Service, Customer, Contact
- Phone and email display on the right
- Smooth scroll anchors on all nav links

### 2. Hero Banner
- Full-screen image carousel (3 slides) powered by Bootstrap Carousel
- Each slide includes a headline, tagline paragraph, and two CTA buttons (*Read More* / *Book Now*)
- Left/right arrow navigation

### 3. Our Services
- 3-column card grid (Cosmetic, Nails, Hairdressing)
- Icon images + description for each service
- *Read More* CTA below the grid

### 4. About
- Brand story paragraph with a decorative background image
- Covers founding year, location, team credentials, and values

### 5. Customer Feedback
- Testimonial carousel (3 quotes) with client name, role, and review text
- Chevron navigation arrows

### 6. Contact / Book a Call
- Left: form with Name, Email, Phone, Message fields + Send button
- Right: embedded Google Maps iframe showing New York location

### 7. Footer
- Newsletter subscription form
- Brand description column
- Contact details (address, phone, email, hours)
- Information links (About, Services, Careers, Privacy Policy, etc.)
- My Account links (Sign In, Register, Appointments, etc.)
- Copyright bar with language switcher + social icons

## 🌐 Multi-language Support

The template ships in **3 languages**, each as a self-contained `index.html`:

| Language | Path | Active label |
|---|---|---|
| 🇺🇸 English (US) | `index.html` | `EN – English` |
| 🇧🇷 Português (BR) | `pt/index.html` | `PT – Português` |
| 🇪🇸 Español | `es/index.html` | `ES – Español` |

A language switcher dropdown is placed in the footer copyright bar on all three pages. The current language is highlighted as active and non-clickable; the other two link to their respective pages.

## 📱 Responsive Breakpoints

The layout is fully responsive using Bootstrap's grid and custom media queries in `responsive.css`:

- **≥ 1200px** — Full desktop layout
- **992px – 1199px** — Adjusted font sizes and spacing
- **768px – 991px** — Collapsed navbar, stacked columns
- **< 768px** — Mobile-first single column layout
